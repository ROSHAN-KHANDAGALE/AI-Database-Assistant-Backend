# Security Policy

## Supported versions

Security fixes are considered for the latest version on the repository's default branch.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

If private vulnerability reporting is enabled for this repository, use GitHub's **Report a vulnerability** feature. Otherwise, contact the project maintainer privately through their GitHub profile and include:

- A description of the affected component and potential impact.
- Steps to reproduce the issue, using synthetic data only.
- Any suggested mitigation.

Please allow maintainers reasonable time to investigate and prepare a fix before publicly disclosing a vulnerability. Do not include API keys, credentials, real user data, or confidential schema files in a report.
